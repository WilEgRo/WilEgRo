## 🚀 Proyectos Destacados

### 📖 LA MARTINA EDITORIAL STUDIO
*AI-powered editorial production system*
Sistema editorial diseñado para transformar información y contenido gastronómico en publicaciones digitales estructuradas. Proyecto principal de investigación y desarrollo.
> **Tech:** TypeScript, React, AI/LLM, IndexedDB.
> **Highlights:** Pipeline editorial IA, memoria acumulativa, motor de composición, renderizado vectorial y generación de PDFs con suite automatizada de tests.

### 🤖 AI Provider Router
*Gateway unificado para trabajar con múltiples proveedores de IA.*
Permite alternar entre modelos locales y APIs remotas sin modificar la aplicación cliente.
> **Conceptos:** OpenAI-compatible APIs, Provider abstraction, estrategias de Retry, Token management y Local LLMs (LM Studio).

### 🧠 Local AI Assistant
*Asistente IA orientado a ejecución local y arquitectura extensible.*
> **Features Previstas:** Memoria persistente, sistema de herramientas, arquitectura de plugins, automatización de tareas e interfaz web.
