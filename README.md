### 🤖 AI Provider Router

Gateway unificado para trabajar con múltiples proveedores y modelos de inteligencia artificial.

**Objetivo:** permitir cambiar entre modelos locales y APIs remotas sin modificar la aplicación que consume el modelo.

**Conceptos:**

* OpenAI-compatible APIs
* Provider abstraction
* Fallbacks
* Retry strategies
* Token management
* Usage tracking
* Local LLMs
